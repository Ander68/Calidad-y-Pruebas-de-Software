# Sitio Web para Minimarket 🛒

Este proyecto es una página web para un minimarket, desarrollada con HTML, CSS, JS y SCSS. Está pensada como una tienda virtual simple.

## Estructura

- `index.html`: Página principal
- `cart.html`, `shop.html`: Páginas de productos y carrito
- `contact.html`: Formulario de contacto
- Carpeta `css/`, `js/`, `img/`: estilos, scripts e imágenes

## Cómo ver el sitio

Solo abrí el archivo `index.html` con tu navegador favorito.
